# GF-SITE External UI Catalog Research & Implementation Record

This document records the exhaustive, source-level audit of all seven external UI catalogs evaluated for Global Fellowship's public website (`GF-SITE`), along with every pattern adopted and harmonized in production code, every strong runner-up, and the architectural rules governing zero-Radix compatibility, accessibility, and performance.

---

## 1. Evaluation Guardrails & Entitlement Truth

Every candidate across all seven catalogs was evaluated against five hard repository requirements:

1. **Zero Radix (`radix-ui` / `@radix-ui/*`):** No direct or transitive Radix imports or dependencies are permitted (`bun run check:foundation`). Every stateful interactive control in `GF-SITE` runs on a single interaction engine: **`@ui-sdk/react` + `@ui-sdk/core`** under `@layer ui-sdk;`.
2. **Zero Runtime Bloat:** Heavy runtime animation or charting libraries (`motion`, `gsap`, `three`, `recharts`, `lucide-react`) are avoided in public pages so mobile LCP, TBT, and bundle size remain lean. Patterns from catalogs that ship `motion` or `lucide-react` are adapted cleanly into zero-dependency React + Tailwind v4 + CSS custom properties or `@ui-sdk/react` primitives.
3. **Global Fellowship Brand & Anti-Mosaic Fit:** Visual craft must honor Global Fellowship's 2026 Marketing Brand Kit palette (Alabaster Ivory `#FCFAF6`, Gallery White `#FFFFFF`, Warm Cream `#F3EDE3`, Deep Navy `#122A3B`, Petrol Blue `#08354D`, Dark Bronze `#614D29`, Muted Gold `#B28B61`), unified `Source Serif 4` + `Nunito` typography, and strict field-safety rules (no maps, pins, per-country counts, worker time zones, or fabricated metrics).
4. **WCAG 2.2 AA+, Keyboard, Reduced Motion, No-JS & B&W Print:** Every adapted widget must pass `@axe-core/playwright` across light and dark mode, support full keyboard navigation and visible focus, honor `prefers-reduced-motion: reduce`, degrade gracefully under `@media (scripting: none)`, and print cleanly on black-and-white church copiers.
