# Organizational Communication Coverage Record

This record is Global Fellowship's canonical **communication capability x audience x channel** completeness ledger across all organizational communications. It records **asset-level status honestly** without conflating automated checks, delegated working completion, or Git merges with human leadership approval (`OVR-15`) or external production runtimes.

## Status Vocabulary (Never Conflate)

- **Working Guidance Complete (Automated Gates Pass; Open Human/External Gates Apply):** Real editable source and verified exports exist in Git, pass `bun run okf:validate`, upstream Python OKF `validate.py --strict`, `bun run verify:brand`, `bun run check:links`, and `bun run check:prose`, and remain explicitly subject to human leadership approval (`OVR-15`) plus any domain-specific Finance, Regional, Legal, Consent, Print, or Portal gates listed in the rightmost column (`OVR-01` through `OVR-24`).
- **Website Phase Handed Off (`OVR-24`):** All brand, OKF, token, asset, copy, and legacy-inventory inputs are complete and handed off in [Website Construction Handoff](website-builder-handoff.md); website page construction and live CMS integration intentionally begin in the next phase so `main` stays on the clean Next.js starter scaffold.
- **Human-Gate Held / External Runtime Pending:** Blocked strictly on human organizational confirmation recorded in [Open Verification Register](open-verification-register.md) or an external live system outside this repository (such as live `Asymmetric-al/core` Postgres deployment, live donor portal destination `OVR-21`, or physical 300dpi press/copier proof `OVR-18`).

_Named-Owner Honesty Note:_ Publicly documented leadership names (Don Oates, Jeremy Beaumont, Conrad O'Brien, Eric Bergen) are cited only where verified in [Source Synthesis](source-synthesis.md). Operational role titles (Finance & Donor Care Lead, Prayer Coordinator, Mobilization Lead, Security Lead, Regional Directors, Web Lead) remain role titles until leadership assigns named custodians under `OVR-15`.
